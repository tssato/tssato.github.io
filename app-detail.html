データ可視化ダッシュボード

■ 課題

日々の売上データを Excel で管理していたが、 「グラフ化が面倒」「視覚的に把握しづらい」という課題があった。

■ 解決

CSV をアップロードするだけで自動でグラフ化する Web アプリを作成。 Chart.js を使用し、折れ線グラフ・棒グラフに対応。

■ 成果

  • データの視覚化がワンクリックで可能に
  • Excel の手作業が不要になり、作業時間を大幅削減
  • スマホでも閲覧可能な UI を実現

■ 使用技術

  • HTML / CSS / JavaScript
  • Chart.js
  • GitHub Pages

ToDo 管理ツール

■ 課題

日々のタスク管理が紙ベースで、 「紛失しやすい」「更新が面倒」という問題があった。

■ 解決

ブラウザ上でタスクを追加・削除でき、 ローカルストレージに自動保存される Web アプリを作成。

■ 成果

  • タスク管理がデジタル化され、紛失リスクがゼロに
  • スマホでも利用可能
  • UI をシンプルにし、直感的に操作できるように設計

■ 使用技術

  • HTML / CSS / JavaScript
  • LocalStorage
  • GitHub Pages

天気 API アプリ

■ 課題

外出前に複数の天気サイトを確認するのが手間だった。

■ 解決

API を利用し、都市名を入力すると天気情報を取得できるアプリを作成。

■ 成果

  • 必要な天気情報を1画面で確認可能
  • API の扱いに習熟
  • レスポンシブ対応でスマホでも見やすい

■ 使用技術

  • HTML / CSS / JavaScript
  • Fetch API
  • GitHub Pages
